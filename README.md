## ✨ What is MediaFlow?

**MediaFlow** is a clean, modern media converter website built with **Next.js** and browser-side **FFmpeg WebAssembly**.

No account. No login screen. No separate converter API required.

### 🛠️ Available tools

- 🎧 **MP3** — Convert video/audio to MP3
- ✂️ **Trim** — Cut media
- ⚡ **Speed** — Slow down or speed up
- 🗜️ **Compress** — Reduce file size
- 📐 **Resize** — Resize video
- 🔊 **Bass Boost** — Boost bass
- 🖤 **Black & White** — Create a B&W video
- 🎚️ **Audio Mix** — Audio processing tools

---

## 🌈 User experience

**1. Upload** 📤  
Choose a video or audio file, or drag & drop it.

**2. Preview** ▶️  
Listen to audio or watch video before converting.

**3. Convert** ⚙️  
Browser-side FFmpeg processes the media and shows conversion progress.

**4. Download** 📥  
Preview the finished result and download it.

---

## ☁️ Deploy on Vercel

Import this repository into **Vercel** and use the default Next.js settings.

No `NEXT_PUBLIC_CONVERTER_API` environment variable is required for the current browser-side conversion flow.

> ℹ️ FFmpeg processing happens on the user's device. Large files can require more time and memory, especially on mobile devices.

---

## 🔒 Privacy-friendly architecture

Media conversion runs in the browser using **FFmpeg WebAssembly**, so the website does not need to upload the user's media to a separate public converter API.

**Upload → Preview → Convert → Result → Download**

All in one smooth flow. 💚
